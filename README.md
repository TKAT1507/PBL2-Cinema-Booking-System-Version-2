# PBL2 Cinema Booking System

A cinema booking system written in C++17 using Qt6 for the UI, with custom `DynamicArray` instead of STL vectors. 

## Build Instructions
1. Ensure Qt6 and CMake are installed.
2. In the project root, run:
```sh
mkdir build
cd build
cmake ..
cmake --build .
```
3. Run the compiled executable. Data files will be automatically copied to the output directory.
